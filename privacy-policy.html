Política de Privacidade — ViaPRO

Última atualização: setembro de 2026

O aplicativo ViaPRO foi desenvolvido como ferramenta de consulta para profissionais de trânsito. Esta política descreve como tratamos as informações dos usuários.

1. Coleta de Dados

O ViaPRO foi projetado para funcionar 100% offline. O aplicativo:

  • Não coleta dados pessoais (nome, e-mail, telefone, CPF).
  • Não exige cadastro ou login para uso.
  • Não rastreia sua localização em segundo plano.
  • Não envia dados para servidores externos.

2. Dados Armazenados Localmente

O aplicativo armazena os seguintes dados apenas no dispositivo do usuário:

  • Favoritos e histórico de consultas — para facilitar o acesso rápido a conteúdos já consultados.
  • Anotações do usuário — textos criados pelo próprio usuário dentro do app.
  • Preferências do app — tema, configurações de exibição.

Esses dados ficam armazenados exclusivamente no dispositivo e podem ser apagados a qualquer momento desinstalando o aplicativo ou limpando os dados nas configurações do Android.

3. Localização (GPS)

A funcionalidade Mapa de Jurisdição utiliza o GPS do dispositivo para identificar a rodovia e o KM em que o usuário se encontra. Esta funcionalidade:

  • Só é ativada quando o usuário solicita explicitamente.
  • Não rastreia a localização em segundo plano.
  • Não armazena nem transmite coordenadas para servidores externos.
  • Os dados de localização são processados localmente e descartados após o uso.

4. Assistente de Sinistros (IA)

O Assistente de Sinistros utiliza inteligência artificial para gerar roteiros de procedimentos. O processamento é realizado localmente no dispositivo. As descrições de sinistros inseridas pelo usuário não são enviadas para servidores externos e não são armazenadas além da sessão atual.

5. Serviços de Terceiros

O ViaPRO não integra serviços de análise (analytics), publicidade ou rastreamento de terceiros. Não utilizamos Google Analytics, Firebase Analytics, Facebook SDK ou qualquer ferramenta similar de coleta de dados.

6. Segurança

Como todos os dados são armazenados localmente no dispositivo, a segurança depende das medidas de proteção do próprio aparelho do usuário (bloqueio de tela, criptografia do dispositivo, etc.).

7. Público-Alvo

O ViaPRO é destinado a profissionais de trânsito (policiais rodoviários, agentes de trânsito) e não é direcionado a menores de 18 anos.

8. Alterações nesta Política

Eventuais alterações serão publicadas nesta página com a data de atualização revisada. Recomendamos a consulta periódica.
